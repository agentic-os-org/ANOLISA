# 架构决策记录

[English](README.md)

本目录集中存放 ANOLISA 的所有架构决策记录（ADR），包括系统级、跨组件及单组件
决策。所有记录共用一个编号序列，并在各自的元数据中注明范围。

每份 ADR 的架构决策以英文原文为准。所有其他语言译文仅供参考；如有差异，以英文
原文为准。

| 编号 | 决策 | 范围 | 状态 |
| --- | --- | --- | --- |
| 0001 | [ANOLISA 架构与组件边界](0001-anolisa-architecture_zh.md) · [英文原文](0001-anolisa-architecture.md) | ANOLISA 系统与 monorepo | Proposed（提议中） |

存放位置、命名、必需内容及资源目录遵循
[文档规范](../../specs/documentation-standard.md#321-architecture-decision-records)。
配套的实现设计保留在各组件目录，并链接到此处对应的 ADR。
