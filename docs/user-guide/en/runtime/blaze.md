# Blaze has moved

[中文版](../../zh/runtime/blaze.md)

Blaze is now maintained in the standalone
[blaze-rs repository](https://github.com/agentic-os-org/blaze-rs) and is no longer
included in the ANOLISA source tree.

Use its [README](https://github.com/agentic-os-org/blaze-rs/blob/main/README.md)
for build and installation instructions, and its
[user guide](https://github.com/agentic-os-org/blaze-rs/blob/main/docs/user-guide/en/blaze.md)
for sandbox lifecycle, networking, guest operations, checkpoints, hibernation,
storage synchronization, and templates.

This page remains as a migration pointer for existing documentation links.
