# 有界命令执行

[English](bounded-execution.md)

`aw-exec` 为单条命令提供字节上限、绝对截止时间和取消能力。原生 Hook 命令及
[本地 Provider Host](provider-host_zh.md) 共用这一进程传输层。
它不依赖 `aw-config`、`aw-core` 或 `aw-provider`。

## API 与归属

`run(&CommandSpec, input, Limits, deadline, &AtomicBool)` 是同步调用。调用方提供
字面量参数、工作目录和完整的子进程环境。库不插入 Shell；使用 Shell 语法时必须明确
指定 `/bin/sh -c ...` 等命令。可执行文件查找方式由调用方选择，环境中仅传入命令需要的变量。

每次调用拥有独立进程组和三条管道。最后一个输入字节写入后关闭 stdin。stdout 和
stderr 分别保留为字节数组，包括非 UTF-8 数据。结果保留原生 `ExitStatus`，区分非零
退出和信号终止。命令提前关闭 stdin 仍可正常返回；`input_bytes_written` 记录写入
管道的字节数，不证明子进程已消费这些数据。

库不解析 JSON、不解释策略判断，也不记录载荷。原生 Adapter 按宿主协议解释命令结果。
Provider Host 另行校验请求/响应绑定、配置及准入效果。传输结果本身不证明宿主采用了策略。

## 执行与清理边界

| 边界 | 行为 |
| --- | --- |
| 输入上限 | 超出字节上限时在创建进程前拒绝 |
| 输出上限 | 分别检查 stdout 与 stderr；任意一路超限即停止进程组并返回类型化错误 |
| 截止时间 | 使用调用方的绝对 `Instant`；多次调用可共用同一截止时间，不重置预算 |
| 取消 | 创建进程前及管道交换期间检查；原子标志和信号处理由调用方管理 |
| stdin 提前关闭 | 保留原生输出/状态，同时报告已写入字节数 |
| 后代继承输出管道 | 在执行期限内等待 EOF；主进程退出不代表后代持有的管道已结束 |
| 清理 | 终止所属进程组，确认没有运行成员后回收主进程；另有固定一秒清理预算 |
| 清理失败 | 返回 `Error::Cleanup`，不返回未经确认的结果或原来的传输错误 |

Linux 实现使用非阻塞管道，每轮读写量有上限，避免管道背压或持续输出占满处理循环。
通过 `waitid(WNOWAIT)` 观察主进程退出，在最后一次进程组信号发送前保留 PID。
清理时检查 `/proc` 中的组成员及其线程，再回收主进程；僵尸线程组主线程仍可能有存活
的其他线程。核查同时受时间和扫描条目上限约束；无法访问进程元数据时明确报告清理错误。

执行期限包括创建进程消耗的时间，但同步 OS 调用和陷入内核等待的进程没有硬实时保证。
调用方不得抢先回收本库的子进程，也不得启用 SIGCHLD 自动回收。错误中的 PID 仅用于诊断，
不得在调用返回后据此发送信号。栈展开时 Drop 尝试终止进程组并非阻塞回收；调用方进程
被强制终止时无法执行清理。

正常完成也会终止命令进程组内的剩余成员。这一传输层用于子进程寿命受单次调用约束的
命令，不用于启动常驻服务。它不修改全局信号处理器、不创建辅助线程，也不回收无关子进程。

## 原生语义与后续防护

当前交付服务于 `tool.before` 和 `tool.after`。调度仍由原生 Adapter 负责：并发调用
各自独立，串行 Hook 保持串行，库不补造 after 事件或审批。`aw-host` 将该传输层与
Provider 协议组合；daemon/CLI 及四框架真实采用验收仍分别增量交付。原生命令调用方
继续直接使用 `aw-exec`。该库不需要新增 `aw.yaml` 字段或 Core profile。

扩展边界区分传输、策略判断和效果执行。Adapter 报告真实原生能力；后续 OS 后端可提供
另外验收的防护能力。进程组清理不是沙箱：子进程可以通过新 session 或进程组逃逸，
回调被杀也可能绕过清理。本库不能声明 final/protected 执行，也不充当 OS 兜底。
既有 Core 保证保持不变，不提供返回成功的占位后端。

执行当前仅支持 Linux，其他平台返回 `UnsupportedPlatform`。

## 开发验证

在安装了 Python 3 的 Linux 环境，从 `src/aw` 执行定向测试：

```bash
cargo test --locked -p aw-exec
```

测试使用本地命令，无需 Agent 登录或模型调用，覆盖字节传输、字面量参数、显式环境/工作目录、
流量上限、截止时间、取消、原生退出状态、后代进程和并发调用。
工作区检查包含该库的测试、Clippy 和 rustdoc：

```bash
python3 src/aw/scripts/check.py
```

工作区检查从仓库根目录执行。命令传输测试不能替代真实 Agent 对 Hook 结果的采用验收。
