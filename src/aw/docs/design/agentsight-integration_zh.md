# 通过 AW run 生命周期接入 AgentSight

[English](agentsight-integration.md)

## 状态与交付顺序

AW 负责原生 Agent 入口和本地执行审计，AgentSight 补充观测，并在后续接收审计
投影。用户配置一次来源，随后通过 `aw run` 启动。正常流程不要求单独查询轨迹，
也不要求手工查找 session ID。

本文替代独立查询命令作为入口的方案。#7626 只交付只读连接器，#7655 依赖它，
实现 #7622 及最小运行生命周期。下文的拟议合同与后续 PR 中的可执行 Schema
分别说明。语义评估仍放在二期。

| 阶段 | 负责 Issue / PR | 依赖 | 交付 |
| --- | --- | --- | --- |
| 有界来源连接器 | #7621 / #7626 | AgentSight 现有 GET API | 只提供库，删除 `aw sight` |
| 运行生命周期、可信关联、证据与上下文 | #7622 / #7655 | #7626 | 启动、纯观测回调、自动关联、可选降级、有界退出清理 |
| 完整能力策略 | #7623 | #7622 | 分能力就绪、required 准入、丢失/恢复及覆盖区间 |
| 公共增量审计 | #7624 | #7622、#7623 | 稳定导出 Schema、枚举、游标和重放 |
| AgentSight 审计消费 | #7625 | #7624 | 获授权的幂等派生持久化 |

先合入 #7626，再将 #7655 更新到 main，让连接器从后者的评审差异中消失。
两个 PR 均不引入语义路由，也不独立改造 #7411 已合入的 PostTool 调度和完成语义。

## 组件归属

| 组件 | 职责 |
| --- | --- |
| `aw run` 与原生 Adapter | 准备原生接入、绑定 AW 实例、持有前台 Agent 和临时注册，报告真实退出并释放实例 |
| `aw-service` | 保留配置、核实原生身份、管理有界实例观测任务、投影证据并记录本地元数据 |
| AW Host 与 Core | 保留已准入动作、原始截止时间、原生效果合同和关键本地审计失败语义 |
| AgentSight 连接器 | 有界 GET、明确的传输信任边界、兼容检查和显式错误，不接管探针或数据库 |
| AgentSight runtime | 持有采集器、查询服务和存储，按证据报告能力 |
| 部署 supervisor | 管理可选合包 worker 的权限、启动 profile 和退出 |

现有同用户私有 socket 是 AW 的信任边界。核实回调字段不能隔离同 Unix 用户的
恶意调用。

部署方向采用本机优先、显式配置来源。AW 持有 Agent 生命周期和本地审计，独立
管理的 AgentSight 服务提供可选观测。字面量 loopback HTTP 继续支持，无需凭据，
并记录 `loopback_unauthenticated`；它不验证监听者身份，返回数据不能独立作为
授权或执行事实的证明。远程连接（含跨容器 IP）使用 HTTPS 与私有凭据，loopback
始终指 AW 所处的网络命名空间。HTTPS 记录 `bearer_supplied`，不声称代理背后的
来源一定实施了 token 校验。两种传输使用相同的[API 合同检查](agentsight-readonly_zh.md)。
后续若强制执行依赖经过认证的本地对端，需要单独准入相应传输；一期不从本地端口
推导这一保证。

## #7622 的最小生命周期

1. 准备阶段校验配置和 Adapter 支持。配置来源并选择 `auto` 时启用观测，`off`
   关闭来源 I/O 和额外原生注册。#7623 实现能力准入前，配置 `required` 必须被拒绝。
2. 绑定时建立实例观测 owner，并进行有界来源兼容探测。查询就绪不能证明采集或
   eBPF 就绪。可选来源失败记入状态，Agent 仍可启动。
3. 没有动作 Provider 时也注册纯观测回调。已有动作回调时复用，避免重复接入。
   纯观测返回原生无操作响应，不阻断、不替换结果，也不重放工具。
4. 从已准入的原生回调字节核实 session/call。服务自动安排有界来源读取。
   Hook 应答等待必要的本地元数据落盘，不等待外部 HTTP。
5. 观测任务属于实例，不依赖某个工具事件一直开放。合并或拒绝超额任务时记录
   缺口，限制队列、来源字节、投影字节、保留会话及查询时长。重复回调不能不断
   创建 worker 或 HTTP 请求。
6. 正常退出和可处理信号只释放当前实例，停止接受观测，有界完成或丢弃在途读取，
   删除自己创建的原生文件。原生退出结果与 AW 清理故障分开记录。启动失败使用
   同一释放路径。launcher 被强杀后可能留下未完成运行，不能标记为成功完成。

最小实现覆盖各 Adapter 已支持的工具回调，不宣称覆盖每个模型回合、原生 Stop
或子 Agent。没有工具调用的运行也有启动生命周期，但可能没有可关联的原生会话。
Agent 进程仍存活时，Stop/继续不结束 AW 实例。来源刷新使用有界快照，不宣称增量订阅。

## 身份与证据

AW 实例、原生会话和来源轨迹分别标识。一个实例可以遇到多个会话，后续实例也可能
恢复旧会话。旧来源历史仍是历史证据，不能算作新实例执行。并发跨实例歧义必须显式
保留。关联核对已准入 Adapter，不能只用来源文本或 PID。进程关联还需要经过评审的
宿主机、boot 与进程启动身份，首期连接器不能提供这些证明。

`aw.evidence/v1` 区分以下字段组，具体可执行合同由 #7655 定义。

| 字段组 | 合同 |
| --- | --- |
| 身份 | 版本、稳定 evidence ID，以及 AW generation/configuration/binding/instance 和事件引用 |
| 来源 | 组件、来源范围、可空来源实例、记录引用及观测到的版本 |
| 关联 | verified/unverified/unassociated、原生 session/call 和核实依据 |
| 时间与覆盖 | 来源时间或未知、接收时间、截止点、显式缺口和裁剪 |
| 内容与派生 | 有界内容引用、编码/摘要、信任类别和转换版本 |
| 执行 | 只有经核实的原生执行事实可以携带执行引用 |

模型回显和复制的工具结果不增加执行次数。记录缺失、存储不可用、响应不合法和身份
未核实分别表示。任意原生 JSON 使用内容字符串及摘要承载，浮点数或任意键不能直接
进入 canonical 元数据域。

## 有界上下文

`aw.evidence-context/v1` 将原始候选、约束、选取证据和缺口绑定到主体与确定性版本。
冻结保留原始事件截止时间与候选，#7411 的完成视图不能改写它们。晚到数据不能改变
已经冻结的快照或决策。

自动观测与事件上下文冻结有不同的生命周期。观测可以在工具回调关闭后完成并另记
元数据，不能重开事件或延长执行预算。一期不为调用接口而强制冻结每次 Hook。
显式服务操作保留给嵌入调用方及后续语义消费者。

选取的来源内容只进入有界内存或显式调用响应。本地 Journal 保存身份、版本、缺口和
结果，不保存凭据、环境快照或原始工具/历史正文。授权调用方取得的正文不宣称已自动脱敏。

## 审计合同与交付

#7624 拟议的公共 `aw.audit/v1` 与私有 Journal、服务 wire 分开。信封包含稳定事件
ID 与 kind、经过认证的 producer scope/generation、AW/原生引用、因果引用、来源
chain/sequence/digest、时间、适用版本、证据/覆盖引用及类型专属结果。未知事实使用
null 或显式缺口。

一期事实包括绑定准备、启动尝试与结果、原生回调、Provider 调用、原生报告的结果、
上下文冻结、观测/覆盖变化及事件/运行终结。调用完成不证明原生采用，退出报告也不
证明观测完整。只有已实现的事实进入可执行导出，语义事件等待二期。

关键本地确认保持持久性。导出和 AgentSight 消费异步进行，使用稳定重放 ID 和有界
分链游标。消费者重访未完成链，报告历史缺失、损坏和滞后。相同 ID/内容是重复，
相同 ID/不同内容是完整性冲突。远端恢复不能重放 AW 动作。AgentSight 只写自己的
派生存储，不读取或改写 AW Journal 私有文件。

## 降级与 all-in-one

| 条件 | 最小行为 |
| --- | --- |
| 没有来源配置或选择 `off` | 保留 AW 动作和本地审计，不读取来源 |
| 可选来源不可用、不兼容或认证失败 | AW 继续，显示脱敏原因和未知/不可用证据 |
| 查询 API 在线，采集状态未知 | 查询兼容可以就绪，采集和覆盖仍为未知 |
| 内核/BTF/权限不满足 eBPF | AW 可用，报告 eBPF 覆盖缺失；用户态轨迹独立可用时继续使用 |
| 来源缺失、延迟或超限 | 记录未知/缺口/裁剪，不能证明没有活动 |
| 要求强制能力 | 实现前拒绝；#7623 只准入有明确就绪证据的能力 |

AgentSight `trace --no-ebpf` 可以采集已支持的用户态轨迹，`serve` 提供查询。
只有 `serve` 在线不能证明采集工作正常。合包必须按能力选择产物和 profile，保留
AW-only 基础，并区分已安装、已启用和已就绪。部署层持有特权探针，`aw run` 不在
Hook 中安装软件、修改文件 capability 或启动 root worker。结束一次运行不能停止共享服务。

## 二期语义内核

新增 `semantic-evaluate` Provider，提供 `semantic.evaluate`，后端使用可替换的
Jev-like 模型。输入包括冻结上下文的引用与版本、版本化问题集和类型化答案 Schema，
共用截止时间。输出绑定相同版本，返回带证据引用的类型化答案，或明确的不可用、
不合法、超时结果。

AW 校验结果后按确定性策略路由到注册动作。模型不能提供任意命令、授予权限或绕过
原生准入。评估与动作分别记录审计，只有经过核实的原生反馈才能声称采用。本次两个
PR 均不引入模型调用、语义评分、问题配置或路由行为。

## 验收与回滚

运行闭环必须在无动作 Provider、无 eBPF 时成立。测试覆盖启动失败、零回调、可信与
伪造 ID、恢复及冲突会话、多实例、慢来源上限、重复回调、队列溢出、正常/信号退出和
所属资源清理，并通过既有 PostTool 回归。HTTP/原生 fixture 不证明真实探针或模型验收。

回滚服务协议前先禁用可选观测，退出所属运行，再用匹配 client/daemon 重启。
保留 Journal 历史和外部 AgentSight 数据。合包、失联 owner 回收、完整覆盖策略和公共
增量导出，均不能描述成只读连接器 PR 已经交付的能力。
