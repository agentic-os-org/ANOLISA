# IPC 接入

[English](ipc-admission.md)

监听器在解码任何 legacy 或 guarded 请求前，执行单一管理信任域的接入策略。
root 隐式获准，其他 UID 来自 daemon 的启动环境。必须取得内核对端凭据。
本阶段不分配工作区所有者，也不提供逐操作授权。

白名单在绑定 Socket 前解析一次。拒绝时关闭连接，不添加旧 bincode 客户端无法解码
的错误变体。客户端不能将响应超时解释为写操作尚未执行。

帧解析和操作执行保留原有语义。连接配额、字节预算与传输截止时间留待单独阶段，
使本改动可以与格式错误帧的结构化响应工作共存。

需要 root 的 Linux Socket 测试使用两个真实非 root UID 建立连接，接纳获准 UID，
同时拒绝另一个 UID。测试采用真实监听器
和临时后端，不需要挂载 Btrfs，也不验证检查点持久化。
